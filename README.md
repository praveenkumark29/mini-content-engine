# Mini Content Engine

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- React
- TypeScript
- Vite
- Axios
- Ollama (Prompt Generation)

## Features

- Upload reference image
- Generate AI prompt
- Background job processing
- Polling for job status
- Generated image preview
- Provider-based architecture
- Repository Pattern
- Service Layer
- Worker Layer

## Run Backend

uvicorn app.main:app --reload

## Run Frontend

npm install
npm run dev

Backend:
http://localhost:8000

Frontend:
http://localhost:5173
